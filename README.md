# NutriTrack
Developed with AndroidStudio

---

**NutriTrack** is a mobile nutrition tracking app built in **Kotlin** using **Jetpack Compose**, and the **MVVM architecture**.
The app helps users monitor their food intake, view nutrition insights, and receive AI-powered tips for healthier eating habits.
The project evolved across multiple stages, from reading CSV data to building a fully featured app with persistent storage and AI integration.
